# Contributing

Thanks for helping improve Traffic Recap.

## Development

Plain JavaScript with no build step and no dependencies.

1. Clone into `<vault>/.obsidian/plugins/traffic-recap/` of a test vault.
2. Enable **Traffic Recap** and turn on **Demo mode** to develop without real accounts.
3. Run tests before opening a pull request:

   ```bash
   node tests/run.js
   ```
